# Writing

Lists in Markdown files and in text on GitHub, such as pull request descriptions, issues and comments, follow the Apple Style Guide rather than The Chicago Manual of Style: an item that completes the lead-in sentence still starts with a capital letter and gets no semicolon, "and" or final period.

## Lists

- Introduce a list with a heading, or with a sentence or fragment that ends with a colon.
- Mark bulleted items with `-`. Number a list only when the order matters.
- Start every item with a capital letter, unless it begins with a name or code literal that starts in lowercase, such as `iOS` or `gh`.
- End an item with a period only if it is a complete sentence. A fragment gets no end punctuation.
- Keep the items of one list the same kind: all fragments or all complete sentences. Numbered steps are always complete sentences.
